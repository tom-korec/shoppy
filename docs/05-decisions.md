# 5. Decisions & open questions

## 5.1 Decision log

| ID   | Decision                                                                                                                                                                                                             | Source                                   |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| D-01 | Backend: **NestJS** (TypeScript)                                                                                                                                                                                     | You chose it                             |
| D-02 | Frontend: **React + Vite** PWA                                                                                                                                                                                       | You chose it                             |
| D-03 | Auth: **own implementation** in the backend; providers: **email/password + Google**                                                                                                                                  | You chose it                             |
| D-04 | Catalog model: reusable **Items** + list **Entries**. One-time entries are free text and can be **promoted** to the catalog                                                                                          | You chose it                             |
| D-05 | Entries have a single free-text **note** that also covers quantity (no separate quantity/unit fields)                                                                                                                | You chose it                             |
| D-06 | Entry lifecycle: **check** → moves to history (who + when); **delete** → removed permanently. History records can be **restored** (moved back, removed from history) or **re-added** (copied, history kept)          | You chose it                             |
| D-07 | Categories: **no global categories**. A predefined set is seeded per household **and** per user, and is customizable. Deleting a category leaves its items uncategorized                                             | You chose it                             |
| D-08 | Email: **Resend** free tier, sending from the domain `korec.dev` (`noreply@shoppy.korec.dev`)                                                                                                                        | You chose it (domain owned)              |
| D-09 | RBAC: fixed roles (Owner/Admin/Member/Viewer) with default permissions, **per-member overrides** capped by a role ceiling. Member management is locked to Owner/Admin. **The matrix in 02-requirements is approved** | You chose it                             |
| D-10 | Permissions apply at **household level** only (no per-list permissions)                                                                                                                                              | You chose it                             |
| D-11 | Invitations: **link, code, email and in-app**; default expiry **7 days**, revocable                                                                                                                                  | You chose it                             |
| D-12 | Personal lists are strictly private. Lists use items from **their own scope only**; items can be **copied** between personal and household catalogs                                                                  | You chose it                             |
| D-13 | A user can be in many households; ownership can be transferred; lists **cannot** move between scopes                                                                                                                 | You chose it                             |
| D-14 | Icons: **icon library** (Lucide)                                                                                                                                                                                     | You chose it                             |
| D-15 | Dashboard: favorites, recently used, pending invitations                                                                                                                                                             | You chose it                             |
| D-16 | Real-time, offline, push and suggestions are **post-MVP**                                                                                                                                                            | You chose it                             |
| D-17 | UI language: **English only**                                                                                                                                                                                        | You chose it                             |
| D-18 | Monorepo on GitHub; docs as Markdown in `/docs`                                                                                                                                                                      | You chose it                             |
| D-19 | Database: **PostgreSQL on Neon**                                                                                                                                                                                     | Claude's proposal (you left it to me)    |
| D-20 | Hosting: **Cloudflare Workers** with static assets (web + `/api` proxy; originally Pages, see D-29) + **Google Cloud Run** (API). Billing account with card is approved                                              | Your choice, after the Vercel comparison |
| D-21 | ORM **Prisma**, validation **Zod** (shared), **TanStack Router/Query**, **Tailwind + shadcn/ui**, **Turborepo**                                                                                                      | Claude's proposal                        |
| D-22 | Sessions: 15-min access JWT + 90-day sliding rotating refresh cookie                                                                                                                                                 | Claude's proposal                        |
| D-23 | **Vercel rejected**: no WebSockets and time-limited streams on its functions would complicate real-time (Phase 6)                                                                                                    | Your choice                              |
| D-24 | App name **Shoppy**, URL **https://shoppy.korec.dev**. `korec.dev` registrar and DNS are on **Cloudflare**                                                                                                           | You chose it                             |
| D-25 | Category **and** item names are unique per scope (case-insensitive). When copying, same-named items in the target are skipped                                                                                        | You chose it                             |
| D-26 | The same item **may** be on a list multiple times (no duplicate guard)                                                                                                                                               | You chose it                             |
| D-27 | Bulk actions: multi-select check/delete, check all / delete all, multi-select restore/re-add/delete in history                                                                                                       | You chose it                             |
| D-28 | History UI: collapsed **Recent history** section below the list with an adaptive window (the 10th most recent record is within 7 days → show 7 days, otherwise 30 days) + a separate full **History** screen         | You chose it                             |

| D-29 | **Cloudflare Workers static assets** instead of Pages + Functions: Cloudflare's recommended path for new projects, config as code (`wrangler.jsonc`), same free-tier economics | Claude, during Phase 0 |
| D-30 | Versions as of Oct 2026: **Nest 12 (ESM)**, **TypeScript 6.0** (typescript-eslint/oxlint tooling doesn't support TS 7 yet), **Prisma 7.10** (8.0 is still a release candidate), **Vite 8**, **React 19.3**, **Zod 4** | Claude, during Phase 0 |
| D-31 | **oxlint** instead of ESLint (ships with the Nest 12 template, fast, type-aware) | Claude, during Phase 0 |
| D-32 | API only accepts requests carrying the proxy secret header (`x-shoppy-proxy-secret`), so the public Cloud Run URL can't bypass the Worker | Claude, during Phase 0 |
| D-33 | Code conventions: one unit per file, **one endpoint per file** (`<verb>-<thing>.endpoint.ts`, single `handle`) delegating to an injected **feature service**, self-explanatory code with comments only for a non-obvious why. Codified in `.claude/rules/` | You chose it |
| D-34 | Claude Code setup in `.claude/`: rules, skills (`new-endpoint`, `new-screen`, `db-migration`, `roadmap-task`, `commit-push-deploy`), agents (`code-reviewer`, `security-reviewer`, `test-writer`, `docs-keeper`), Prettier hook and command allowlist | You chose it |
