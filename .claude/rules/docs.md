# Docs

- `docs/` is the product's source of truth. Keep it consistent with the code.
- Roadmap tasks keep the format `| P#-## | task — status |`, with status `✅ Done`, `⏳ …` (waiting, say on what) or nothing (not started).
- Any decision that changes or adds to the plan gets a decision log row (`D-##`, next free number) with its source ("You chose it", "Claude's proposal", "Claude, during Phase N").
- Requirements use stable IDs (`FR-*`, `NFR-*`). Never renumber; add new ones at the end of their group.
- Write plainly: short sentences, tables for structured facts, no marketing language.
